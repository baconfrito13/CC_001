# Proven patterns

What worked, so it becomes the default. Added and confirmed by `/melhorar` from `win` lessons and
metrics; each pattern also lives where agents use it (the playbook step it names). A pattern that
later fails is demoted with the reason, not silently deleted.

Format, one block per pattern, grouped by phase:

```
### P-NNN · <short name>
- **What:** the practice, concretely.
- **Evidence:** products `<slug>`, `<slug>`; metric before → after, or the outcome.
- **Confirmed:** N× (last YYYY-MM-DD) · **Lives in:** `factory/playbooks/<file>` step …
```
